# PRICE NOTE｜価格追跡・見積もり管理

価格.comの気になる商品を登録して、価格と買い物リストの総額を記録できるWebアプリです。
パソコンやスマートフォンのブラウザーから利用でき、インストールは不要です。

**[PRICE NOTEを開く](https://kapiiii.github.io/kakaku-price-tracker-web/)**

## 主な機能

- **商品URLの一括登録**：価格.comの商品をまとめて登録し、買い物リストとして管理できます。
- **手動更新・毎日の自動更新**：ボタンで価格を取得するほか、毎日指定した時刻に自動で更新できます。
- **3つの総額比較**：初回登録時または指定した保存時点・現在の最安・ショップ除外後の総額を比較できます。
- **ショップの除外**：利用しないショップを複数選び、残ったショップでの最安価格と総額をすぐに計算できます。
- **価格と総額の履歴**：商品の価格履歴や、リスト全体の値動きをグラフ・表で確認できます。
- **取得失敗時の価格引き継ぎ**：更新できなかった商品には、最後に取得できた価格を表示します。
- **商品URLリストの共有**：商品リストをテキスト・共有リンク・TXTファイルで渡せます。
- **CSV出力・バックアップ**：比較結果や総額の履歴をCSVで保存し、登録データをJSONで保存・復元できます。
- **アカウントごとの保存**：商品・履歴・設定を自分のアカウントに保存し、別の端末でも利用できます。

## はじめに

1. サイトを開き、**「GitHubでログイン / はじめる」**からログインします。GitHubアカウントが必要です。
2. **「商品を追加」**を押し、価格.comの商品ページURLを貼り付けます。複数の商品は1行に1つずつ入力してください。
3. 取得が完了すると、商品の価格とリスト全体の総額が表示されます。

登録した商品・価格履歴・設定はアカウントごとに保存されます。同じGitHubアカウントでログインすれば、別の端末でも続きから利用できます。
ログイン前に**「デモを見てみる」**を押すと、架空の商品・価格で画面を試せます。

## 総額を比較する

「価格比較」画面には、次の3つの総額が表示されます。

| 表示                 | 内容                                                         |
| -------------------- | ------------------------------------------------------------ |
| 指定時点の総額       | 初回登録時、または選んだ保存日時の価格の合計                 |
| 現在の最安総額       | 最後に取得した各商品の最安価格の合計。指定時点との差額も表示 |
| ショップ除外後の総額 | 除外したショップ以外で、各商品の最安価格を選んだ合計         |

### 比較する日時を選ぶ

**「指定時点の総額」の隣にあるプルダウン**から選びます。

- 先頭の**「初回登録時点」**が初期値です。各商品を最初に登録したときの価格を合算します。
- その下には価格を保存した日時が並びます。選ぶと、総額・商品一覧の価格・差額がまとめて切り替わります。
- 選択した時点は自動保存され、次回訪問時や価格更新後も引き継がれます。

### ショップを除外する

**「除外するショップ」**で、計算から外したいショップにチェックを付けます。複数選択でき、ショップ名で検索もできます。
スマートフォンでは**「ショップ除外」**から一覧を開けます。「設定・データ」や「商品ごとの履歴」からも切り替えられます。

選択・解除すると、その場で除外後の価格と総額を再計算します。ページやショップ一覧のスクロール位置は維持され、除外設定も自動保存されます。
すべて戻したいときは**「除外をすべて解除」**を押してください。

### 金額の見方

- **「—」**：価格を取得できていない、選んだ時点では未登録、または除外後に購入候補のショップがない状態です。
- **「小計」**：全商品の価格がそろっていないため、価格が分かる商品のみを合算しています。取得件数も確認してください。
- **「前回価格」**：最新の取得に失敗したため、最後に取得できた価格を表示しています。商品詳細で取得日時と理由を確認できます。
- 差額は、両方の時点に価格がある同じ商品だけで比較します。
- 初回登録時に取得できなかった価格は、その後取得できても初回価格として補いません。過去の記録にも後の価格を入れません。

## 価格を更新する

### 手動で更新する

**「価格を一括更新」**を押すと、登録商品の価格を順番に取得します。すべての処理が終わると、保存日時付きの履歴として記録されます。

取得には時間がかかります。途中で画面を閉じた場合は、次回アクセス時に表示される**「更新を再開」**から続けられます。
**「中止」**を押すと、その更新の確定を取りやめ、更新前の価格を保持します。

### 毎日自動で更新する

初期設定は**毎日09:00開始（日本時間）・ON**です。パソコンやブラウザーを開いておく必要はありません。

**「設定・データ」**で自動更新のON/OFFと開始時刻を変更し、**「設定を保存」**を押してください。
商品は順番に処理するため、開始から完了まで数分以上かかる場合があります。混雑やサービスの休止などで遅れたり、更新できなかったりすることもあります。

OFFにすると次回以降の自動更新が止まります。すでに実行中の更新は、更新欄の「中止」で止められます。

## 価格の履歴を見る

- **「総額の推移」**：リスト全体の値動きをグラフと表で確認できます。期間や集計対象を切り替え、保存時点ごとの内訳も見られます。
- **「商品ごとの履歴」**：商品を選び、最新のショップ別価格と過去の価格を確認できます。

総額の履歴は、**当時の商品構成**と**現在の登録商品にそろえた比較**を切り替えられます。
商品構成や価格の取得範囲が変わった区間では、単純な値下がりと区別するためグラフの線が途切れます。
過去の「ショップ除外後」の金額も、現在の除外設定で再計算されます。

## 商品URLリストを共有する

1. 画面上部の**「リストを共有」**を押します。
2. 共有する商品を選びます。必要なら**「商品名も含める」**をONにします。
3. **「リストをコピー」**でテキストをコピーするか、**「共有リンクをコピー」**で一覧ページへのリンクを作ります。TXT保存もできます。

共有リンクを受け取った人は、ログインせずに商品一覧を閲覧できます。
自分のリストに登録したい場合は、共有ページの**「URLリストをコピー」**を押し、自分のPRICE
NOTEにログインして「商品を追加」に貼り付けてください。

共有されるのは商品URLと任意の商品名です。価格履歴や除外設定は含まれません。
共有リンクは作成時点の一覧を表すため、元のリストを変更しても共有内容は自動で変わりません。変更後の内容を渡すときは、新しいリンクを作ってください。
リンクを知っている人は一覧を閲覧できます。

商品名を含めてリンクが長くなりすぎる場合は、商品名をOFFにするか、テキストのコピー・TXT保存を利用してください。
コピーができないときは、画面の表示欄を選択して手動でコピーできます。

## 商品の整理・データの保存

**「設定・データ」**から、次の操作ができます。

- **商品の削除**：現在のリストから商品を外します。過去の価格履歴や当時の内訳は保持されます。
- **バックアップを保存**：登録商品・価格履歴・設定をJSONファイルで保存します。
- **JSONから復元**：保存したバックアップを読み込みます。現在のデータを置き換える操作なので、復元前に内容を確認してください。
- **保存HTMLを読み込む**：自動取得できない場合に、価格.comの商品ページをブラウザーで「HTMLのみ」として保存して読み込めます。

価格比較や総額推移の画面では、**「CSV保存」**から表示内容を保存できます。商品の登録上限は100件です。

## 利用上の注意

表示価格は税込販売価格です。送料・ポイント・会員割引は総額に含めていません。購入前に、各販売店で価格・送料・在庫を確認してください。

価格を取得できなかった場合は前回の価格を引き継ぐため、表示された価格の取得日時も確認してください。
価格.comの仕様変更やアクセス制限、サービスの休止などにより、取得・自動更新が利用できない場合があります。

PRICE NOTEは価格.comの非公式ツールです。
